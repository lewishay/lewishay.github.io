Crystal Cavern

Crystal Cavern is a reverb audio plugin (VST) for Windows and MacOS.

There are four self-explanatory controls to tweak the behaviour of the reverb - Decay, Low cut, High cut and Mix. In addition, there are three tonal options, which alter the character and EQ of the reverb.

Technologies used:

  • C++
  • CMake
  • JUCE
  • Aseprite for the graphics

Development period: 2026

BlueLime

BlueLime is a music player application for Windows.

Features include:

  • Playback of local audio files, including changing playback speed and pitch
  • Responsive UI that adapts to window size
  • Loading a music library from a specified directory, automatically saving library data and album art to a cache for quicker subsequent loading times
  • Asynchronous scanning of file metadata to obtain track information and album art, updating the cache when new files have been added or when files have been updated/deleted
  • Settings to assign custom keybinds, change the library directory, reload library and rebuild caches

Technologies used:

  • C# and XAML
  • Windows Presentation Foundation (WPF)
  • Visual Studio
  • .NET packages: NAudio, SoundTouch.Net, TagLibSharp, Newtonsoft.Json
  • MSTest for unit and integration testing

Development period: 2025

SpringView

SpringView is a simple app that captures and streams desktop video & audio. This stream is then accessible from a secondary device on the local network.

The motivation to make this was so that I could use my phone as a second screen to continue watching something playing on my PC while in another room. I had previously tried screen sharing via Discord, but the quality and connection stability was bad. I then tried remote access software AnyDesk and TeamViewer which had better quality, but their apps were resource-heavy and ultimately felt too bloated for my use case.

Features include:

  • Capturing of desktop screen and system audio
  • Hosting the content on the local network, accessible via a web browser
  • Outputting the stream files as a sliding window of short segments, ensuring that only a small amount of disk space is used, and automatically cleaning them up after the stream is stopped

Technologies used:

  • Java
  • Spring Boot
  • Maven
  • FFmpeg
  • HTTP Live Streaming (HLS)

Development period: 2026

Ultex

Ultex is a 2D space shooter game.

When I started this project, I had no experience using the language (C#) or the framework (Unity). The idea was to teach myself something new while also exploring a passion of mine. Development was started in 2023 and finished in 2025, although this was intermittent and the project was not being actively worked on for most of 2024.

Ultex was built as a WebGL component, which means it can be played in the browser.

Technologies used:

  • C# and Unity
  • Aseprite for sprites/animations/background
  • Reaper for music and sound effects

Development period: 2023 - 2025

ImageReplacer

ImageReplacer is a Firefox extension that can replace images across the web by modifying network requests.

Features include:

  • Select a supported element on the current webpage to replace, and enter a URL of an image to replace it
  • Store a replacement rule that will persist for future requests
  • View, modify or delete existing replacement rules

The extension was uploaded to Mozilla's developer hub where it has been approved for usage. Further details can be found in the project's README.

Technologies used:

  • Typescript / Javascript
  • Node.js

Development period: 2026

RandoChoice

RandoChoice is an Android app which will pick a random option from a list of choices.

I became interested in developing an Android app as I liked the idea of creating something that I could install and use on my phone. The recommended language for Android development is Kotlin which appealed to me as it was similar to other languages I knew at the time, so this project allowed me to explore a new language without a steep learning curve.

Features include:

  • Input a list of choices to be randomly selected from
  • Save, load, and delete lists from local storage

Technologies used:

  • Kotlin
  • Gradle
  • Android Studio

Development period: 2021 - 2022
